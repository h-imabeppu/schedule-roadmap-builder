# Schedule Roadmap Builder

Windows用の日程管理ツール（仕様v0.4c対応）です。表に大項目・小項目・マイルストーン、前工程、工数、担当者を入力すると、稼働日の日程とカレンダーの帯を再計算します。外部通信は行いません。

## 実行環境

- Windows x64、.NET 9 Windows Desktop Runtimeが必要です（ランタイムは同梱しません）。
- ビルドには.NET 9 SDKを使用します。PPT生成にPowerPointは不要です。

## 使い方

新規作成の場合は、設定を編集し、項目を入力してから必要な形式に出力します。

1. アプリを起動し、「ファイル → 開く」で `samples/sample.srb.json` を開きます。新規作成も可能です。
2. ツールバーで行を追加・挿入・削除・上下移動します。選択した1行ずつの操作です。小項目とマイルストーンは、直前の大項目に所属します。大項目を移動しても配下の行は一緒には移動しません。
3. 項目名、前工程No（カンマ区切り）、工数、開始日、ステータス、担当を編集します。種別・ステータス・担当は選んだ時点で再計算し、帯の色も即座に反映します。テキストはセルの編集確定後に反映します。開始日を空欄にすると手入力を解除します。灰色は計算値、赤系はエラー、黄色は警告です。セルにマウスを置くと理由が表示されます。
4. 「設定」でステータス・担当者・休日を編集します。担当者の色コードの横に色見本を表示します。色セルをダブルクリックすると色を選べます。祝日はテキスト貼り付け・CSV（UTF-8 / Shift_JIS）で取り込めます。他のプロジェクトから設定だけを置換・追加することもできます。
5. 表示開始・終了を指定して「期間を適用」を押します。「自動」は計算済みの日程を含む月単位の期間にします。92日以下は全日付、93日以上は月曜のみになります。後からモードを変更できます。
6. 保存すると `.srb.json` が作成され、上書き前の内容は `.srb.json.bak` に1世代残ります。日程計算値・表示Noは保存されません。未保存時はタイトルに `*` が付きます。
7. 「ファイル → PNG出力」で全項目または大項目・マイルストーンを選び、全行を1枚のPNGにします。共有先へのアップロードは手動で行ってください。
8. 大項目・マイルストーンを選び「PPT表示 ON/OFF」で出力対象を切り替えます（現在の状態は項目セルのツールチップ）。「ファイル → PPT出力」で期間・モード・今日の線を指定します。16:9・1枚に、ヘッダ・大項目名・網掛け・罫線を1つの編集可能な表として出力します。矢印・白縁の◆・名称・今日の線は表から独立した図形です。PPT非表示の大項目に所属するマイルストーンは、その大項目行とともに出力しません。75列を超える表のPowerPointでの表示・編集は、下記の人手確認が必要です。
9. 「ファイル → Excel出力」で全項目または大項目・マイルストーンを選び、保存先を指定します。現在の表示期間・表示モードで、1枚の「日程」シートに出力します。左11列はNo／種別／大項目／項目／前工程／ステータス／備考／工数／開始日／完了予定日／担当です。見出しの「担当」でフィルタを使えます。大項目名を各行に残し、開始・完了予定日は日付、工数は数値、帯は担当者色（完了は濃い灰色）にします。見出し行の下・担当列の右でウィンドウ枠を固定します。Excelの取り込み・数式・マクロはありません。

表の左11列（表示チェック＋従来の10列）は横スクロール時も固定され、表とカレンダーの縦スクロールは共通です。削除時は参照元を確認し、前工程参照も解除されます。Undoはありません。

### 表示チェックと表示モード（v0.4c）

- 一番左の「表示」は初期値ONです。大項目を切り替えると配下の小項目・マイルストーンも即時に同じ状態になります。
- 小項目・マイルストーンをONにすると、その大項目だけもONになります。兄弟の行は変わりません。子をOFFにしても親はOFFになりません。所属のないマイルストーンは自分だけを切り替えます。
- ツールバーの「全表示」はチェックに関係なく全行を表示します。「チェック済みだけ表示」はONの行だけを表示し、OFFにした行はすぐ消えます。戻すときは「全表示」に切り替えてからチェックを入れます。ステータスバーに表示行数／全行数を表示します。
- 表示チェックと表示モードは保存します。従来のファイルは全行ON・全表示として読み込みます。非表示でも日程計算・前工程・No・大項目の期間集計には含まれます。
- PNG・Excel・PPTにも出力時の表示モードを適用します。「全項目」／「大項目とマイルストーンのみ」はその後に適用します。PPTはさらに従来の「PPTに表示」がONの行に限定します。PPT対象外の大項目に属するマイルストーンを省略する従来動作は維持します。
- サンプルは小項目2件をOFF、表示モードは全表示にしています。

PPTの日付は折り返しなしとし、全日付はMeiryo UIの「30」の実測により4～10ptを0.5pt刻みで選びます。4ptでも入らない場合は警告します。月曜のみは週単位で日のセルを結合し、5日未満の週は空欄にします。◆は一辺0.12インチ固定（行高がそれより小さい場合のみ行高の80%）です。Excelの月・CWは表示範囲内で月ごと・週ごとにセル結合し、左揃えにします。

### ズーム・スクロール

| 操作 | 動作 |
|---|---|
| ホイール | 縦スクロール |
| Shift＋ホイール | 左の表を固定したまま、カレンダーを横スクロール |
| Ctrl＋ホイール | 10%刻みで拡大・縮小 |
| Ctrl＋「+」／Ctrl＋「-」（テンキーも可） | 拡大・縮小 |
| Ctrl＋0（テンキーも可） | 100%に戻す |

倍率は50%～200%で、表とカレンダーの文字・行高・列幅・ヘッダ高を一緒に変更します。ステータスバーに倍率を表示し、先頭の表示行を維持します。倍率は保存せず、起動時は100%です。今日の列は、行境界で途切れない赤い縦線1本で示します。

## ビルド・テスト

```powershell
dotnet restore ScheduleRoadmapBuilder.sln --disable-parallel
dotnet build -warnaserror
dotnet test
```

テストは実サンプルから `samples/output/sample.png`、`sample-AllDays.pptx`（4か月・121列）、`sample-Mondays.pptx`（4か月）、`sample.xlsx` を再生成します。チェック済みだけ表示の `sample-Checked.xlsx` と `sample-Mondays-Checked.pptx` も生成します。PPTとExcelのOpenXmlValidatorエラー0件、PPTの単一表・結合・網掛け・罫線・図形位置と重なり順、Excelのフィルタ・固定枠・日付書式・所属・色・行数を検証します。3か月・93列の既存回帰テストも維持しています。v0.4cの◆固定寸法・日付の折り返しなし／実測サイズ／週結合・Excel月/CW結合・チェック連動・旧JSON互換・計算不変・全出力の絞り込みも検証します。画面起動・編集・並べ替え・コンボボックスと表示チェックの即時反映・表示モード・ズームキーもWindowsのSTAスレッドで検証します。200行・6か月で30回のズームと再描画を測り、1回250ms未満かつ先頭行が維持されることを検証します。

単一exe化でSDKが自動追加する承認範囲外の解析用パッケージを避けるため、`EnableSingleFileAnalyzer=false` にしています。トリミング・AOTは使用しません。通常のコンパイラー警告とテストは有効です。

## exeの作成

```powershell
dotnet publish src/ScheduleRoadmapBuilder.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

PowerShellでバックスラッシュを使用する場合：

```powershell
dotnet publish src\ScheduleRoadmapBuilder.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

出力先は `publish/ScheduleRoadmapBuilder.App.exe` です。アプリ本体は単一exeですが、配布時はREADME・サンプル・`THIRD_PARTY_NOTICES.md`・`licenses/` を含む **publishフォルダー全体** を渡してください。サンプルのPNG/PPT/Excelはテスト生成物で、exeには埋め込みません。

publish後に `powershell -ExecutionPolicy Bypass -File tools\Verify-Distribution.ps1` を実行すると、依存台帳の網羅性・ライセンス原文の存在、配布先の同梱ファイルのハッシュ一致、単一exeの存在を検査します。

ライセンス台帳の再生成は、復元後に `powershell -ExecutionPolicy Bypass -File tools\Collect-ThirdPartyNotices.ps1` で実行できます（公式配布元への接続が必要）。初版はMITの実行用3パッケージ、開発・テスト用15パッケージを記録しています。社内配布の承認や法的判断は別途必要です。

## フォルダ構成と開発資料

- `src/`：アプリと日程計算のソース
- `tests/`：テスト
- `samples/`：サンプル
- `docs/`：仕様と開発の記録（`docs/specification.md`、`docs/progress.md`）
- `tools/`：配布物の検証などのツール
- `licenses/`：第三者ライセンスの原文。詳細は `THIRD_PARTY_NOTICES.md` を参照してください。
