# 受け入れ確認の手順（人が行う確認）

このファイルは、旧 README.md の「人が行う受け入れ確認」の節を移したものです。
確認には `samples/sample.srb.json` を使います。サンプルを上書きしないよう、「名前を付けて保存」で別のファイルにしてから確認してください。

## 画面

- [ ] exeを起動してサンプルを開き、次の操作ができること。
  - 行の追加・挿入・削除・上下移動
  - 行を動かしたときに、前工程のNoが追従すること
  - 設定の変更
  - 未保存のまま閉じようとしたときに、確認が表示されること
- [ ] カレンダーの表示が正しいこと。
  - 土日・祝・休が灰色
  - 担当者の色、完了扱いの濃い灰色
  - 大項目の細い帯、◆
  - 今日の赤い縦線が1本で、行の境目で途切れないこと
  - 今日が表示期間に入っていない場合は、期間を今日まで広げて確認する
- [ ] 担当やステータスを選んだ直後に、他のセルを選ばなくても色が変わること。
- [ ] 設定画面の色見本が、色コードと一致していること。
- [ ] ズームの操作ができること。
  - Ctrl＋ホイール、Ctrl＋0／＋／−（テンキーを含む）で、50%〜200%の範囲で拡大・縮小できる
  - 倍率の表示、全体の拡大・縮小、先頭行の維持
  - 200行・6か月の表示でも、連続した操作に追従すること
- [ ] スクロールの操作ができること。
  - ホイールで縦にスクロールする
  - Shift＋ホイールで、左の表を固定したまま横にスクロールする

## 表示チェック

- [ ] 大項目・小項目・マイルストーンのチェックが、規則どおりに連動すること。
- [ ] 表示モードを切り替えると、すぐに表示が変わること。
- [ ] 「チェック済みだけ表示」の状態でPNG・Excel・PPTを出力し、出力された行が画面の絞り込みと一致すること。
  - PPTでは、「PPTに表示」による対象の制限も適用されること

## PNG

- [ ] 全項目と要約のPNGを出力して開き、次の点を確認する。
  - 画面に表示されていない行も含まれていること
  - 日本語の文字と帯が読めること

## PPT

- [ ] 2026/11/01〜2027/01/31・全日付で出力する。
  - PowerPointで開いたときに、修復を求められないこと
  - 見た目に問題がないこと
  - 図形を編集できること
- [ ] 2026/11/01〜2027/02/28・月曜のみで出力する。
  - 修復を求められないこと
  - 月・CW・矢印・マイルストーン名の配置に問題がないこと
- [ ] CW44が空欄であること。
- [ ] グリッド線と日付の数字が読めること。
- [ ] 日付が折り返されず、1行で表示されていること（4か月の全日付、4か月の月曜のみ）。
- [ ] ◆に白い縁があること。大きさが適切であること。名称が◆の右隣（右端では真上）にあること。
- [ ] 75列を超える表を、PowerPointで開いて編集できること。
  - セルの塗りつぶしなどを変更できる
- [ ] 矢印や◆をドラッグしても、表が一緒に動かないこと。

## Excel

- [ ] 担当者で、フィルタをかけられること。
- [ ] 各行に、所属する大項目の名前が入っていること。
- [ ] 開始日と完了予定日が、日付として認識されること。
- [ ] ウィンドウ枠が固定されていること。
- [ ] 全項目と要約で、行数・色・◆が正しいこと。
- [ ] 月とCWのセルが、表示範囲の両端も含めて結合され、文字が左揃えになっていること。

## 注意

- AIによる自動検証では、PowerPointやExcelで実際に表示・操作したときの動作までは保証できません。
- 75列を超えるPPTの表で問題が見つかった場合は、仕様に従って列の構成を見直します。
