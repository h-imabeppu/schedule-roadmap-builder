# Schedule Roadmap Builder

日程表を入力するだけで、稼働日に沿った日程を自動計算し、カレンダーで確認できるWindows用ツールです。
顧客報告用の「全体日程」を、PowerPointのスライド1枚にそのまま出力できます。

- 前工程と工数から、開始日と完了予定日を自動で計算します（土日・祝日・休日を除外）。
- 大項目（顧客に見せる工程）と小項目（担当者ごとの作業）の2階層で管理できます。
- PowerPoint（全体日程1枚）、Excel（担当者でフィルタ可能）、PNG（共有用）に出力できます。
- 外部との通信は行いません。PowerPointやExcelがインストールされていなくても、ファイルを出力できます。

## 動作環境

| 用途 | 必要なもの |
|---|---|
| 実行 | Windows x64、[.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) |
| ビルド | .NET 9 SDK |

## はじめかた

1. 「[exeの作成](#exeの作成)」の手順でexeを作成し、`publish/ScheduleRoadmapBuilder.App.exe` を起動します。
2. 「ファイル → 開く」で `samples/sample.srb.json` を開くと、入力例を確認できます。
   - サンプルを書き換えたくない場合は、「名前を付けて保存」で別のファイルとして保存してください。
3. 新しく作る場合は、「ファイル → 新規」を選び、次の順に進めます。
   1. 担当者・ステータス・祝日を設定する
   2. 項目を入力する
   3. 必要な形式で出力する

## 使い方

### 1. 設定（メニュー「設定」）

- **担当者：** 名前と色を設定します。色のセルをダブルクリックすると、色を選べます。ここで設定した色が、カレンダーの帯やPPTの矢印の色になります。
- **ステータス：** 名前と「完了扱い」を設定します。完了扱いの項目は、灰色で表示されます。
- **祝日・休日：** 1件ずつ入力するほか、テキストの貼り付けやCSVでまとめて取り込めます。
  - 形式は `yyyy-MM-dd,名称` または `yyyy/M/d,名称` です。
  - 内閣府の「国民の祝日」CSVも、そのまま取り込めます。
- **他のファイルからの取り込み：** 他のファイルから、設定だけを取り込むこともできます。

### 2. 項目の入力

| 列 | 内容 |
|---|---|
| 表示 | 表示するかどうかのチェック（「表示チェック」を参照） |
| 種別 | 大項目／小項目／マイルストーン（◆） |
| 項目 | 作業名 |
| 前工程 | 先に終わっている必要がある項目のNo（複数の場合はカンマ区切り。例：`2,3`） |
| 工数 | 稼働日数 |
| 開始日 | 前工程が無い項目は手入力します。前工程がある項目は、前工程が終わった翌稼働日になります（手入力で後ろにずらすこともできます） |
| 完了予定日 | 自動で計算されます |
| ステータス・担当・備考 | 必要に応じて入力します |

- 小項目とマイルストーンは、すぐ上にある大項目に所属します。
- 大項目の期間は、所属する項目から自動で集計されます。
- 入力を誤ったセルは赤、注意が必要なセルは黄色で表示されます。セルにマウスを置くと、理由が表示されます。
- 行の追加・挿入・削除・上下移動は、ツールバーから行います。
- 前工程のNoは、行を移動しても自動で追従します。

### 3. 表示期間

- 開始日と終了日を指定して、「期間を適用」を押します。
- 「自動」を押すと、全項目が入る期間を月単位で設定します。
- 日付の表示には、「全日付」と「月曜のみ」の2種類があります。
  - 期間が3か月程度までなら「全日付」、それより長い場合は「月曜のみ」が自動で選ばれます。
  - 選ばれた後で、手動で切り替えることもできます。

### 4. 表示チェック

- 表の一番左にあるチェックで、表示する行を選べます。
- 大項目のチェックを外すと、所属する項目のチェックもすべて外れます。
- 小項目にチェックを入れると、所属する大項目にもチェックが入ります。
- ツールバーで「全表示」と「チェック済みだけ表示」を切り替えられます。
- 非表示にした行も、日程の計算には含まれます。

### 5. 出力（メニュー「ファイル」）

すべての出力で、出力する時点の表示期間と表示チェックの状態が反映されます。

| 出力 | 内容 | 主な用途 |
|---|---|---|
| PPT出力 | 16:9のスライド1枚に、大項目とマイルストーンの全体日程を出力します。カレンダー部分は編集可能な表、矢印と◆は個別の図形です | 顧客・上司への報告 |
| Excel出力 | 全項目を、カレンダー付きの1枚のシートに出力します。見出しにフィルタが付いています | 担当者が自分の作業を絞り込んで確認する |
| PNG出力 | 画面の表とカレンダーを、画像1枚に出力します | Teamsなどでの共有 |

**PPTに表示する項目の指定**
- 大項目とマイルストーンは、「PPT表示 ON/OFF」で、PPTに表示するかどうかを個別に指定できます。

**保存**
- `.srb.json` 形式で保存します。
- 上書きする前の内容が、`.srb.json.bak` として1世代だけ残ります。

## 操作のヒント

| 操作 | 動作 |
|---|---|
| ホイール | 縦スクロール |
| Shift＋ホイール | 横スクロール（左の表は固定されます） |
| Ctrl＋ホイール | 拡大・縮小（50%〜200%） |
| Ctrl＋「+」／Ctrl＋「-」 | 拡大・縮小 |
| Ctrl＋0 | 100%に戻す |

画面を共有しながら会議をするときは、Ctrl＋ホイールで見やすい大きさに調整してください。

## exeの作成

```
dotnet publish src/ScheduleRoadmapBuilder.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

- exeは `publish/ScheduleRoadmapBuilder.App.exe` に出力されます。
- 他の人に渡すときは、ライセンスファイルを含む `publish` フォルダを丸ごと渡してください。

## 開発者向け

### ビルドとテスト

```
dotnet restore ScheduleRoadmapBuilder.sln --disable-parallel
dotnet build -warnaserror
dotnet test
```

- テストを実行すると、`samples/output/` にサンプルの出力（PPT・Excel・PNG）が生成されます。
- `samples/output/` はgitで管理していません。

### フォルダ構成

| フォルダ | 内容 |
|---|---|
| `src/` | アプリ本体と日程計算のソース |
| `tests/` | テスト |
| `samples/` | サンプルデータ |
| `docs/` | 仕様書（`specification.md`）、開発の記録（`progress.md`）、受け入れ確認の手順（`acceptance-checklist.md`） |
| `tools/` | 配布物の検証、ライセンス台帳の生成に使うスクリプト |
