## 1. 目的

- 項目、前工程、工数、開始日、担当者などを入力すると日程が自動で計算され、右側のカレンダーに帯で表示される日程管理ツールを作る。
- 大項目の全体日程を、PowerPointのスライド1枚（.pptx）に出力する。
- 閲覧者と共有するために、PNG画像とExcelファイル（v0.4）を出力する。作成したファイルは、利用者が手動でTeamsに置く。

## 2. 前提・技術選定

| 項目 | 内容 |
|---|---|
| 形態 | Windowsデスクトップアプリ（exe） |
| 言語・UI | C# / WinForms |
| .NET | `net9.0-windows` |
| 利用者 | 編集者は1人。閲覧者は、出力したPNG・Excel・PPTで見る |
| 保存形式 | JSON（拡張子 `.srb.json`）。プロジェクト1件をファイル1つにまとめる |
| Excelとの連携 | 出力のみ行う（§9.5）。取り込みは行わない。xlsxの生成には既存の DocumentFormat.OpenXml を使い、パッケージは追加しない（v0.4） |
| PPTの出力 | DocumentFormat.OpenXml を使う。PowerPointがインストールされていない環境でも生成できること |
| PNGの出力 | .NET標準の System.Drawing（WinForms）を使う。追加のパッケージは使わない |
| テスト | xUnit |
| 外部通信 | なし |

### 2.1 承認済みの第三者パッケージ

下表のパッケージは、承認を待たずに導入してよい。

- 導入するときは、使うバージョンのライセンスを公式の配布元で確認する。
- 確認した結果を `THIRD_PARTY_NOTICES.md` と `licenses/` に記録する。
- ライセンスが表の内容と違った場合は、台帳に「要確認」と記録して作業を続ける。

| パッケージ | 用途 | 想定ライセンス | 配布物に含むか |
|---|---|---|---|
| DocumentFormat.OpenXml | PPT・Excelの出力 | MIT | 含む |
| xunit | テスト | Apache-2.0 | 含まない |
| xunit.runner.visualstudio | テスト | Apache-2.0 | 含まない |
| Microsoft.NET.Test.Sdk | テスト | MIT | 含まない |

### 2.2 推移的依存の扱い

**導入してよい範囲**
- §2.1の4パッケージを追加したことで、NuGetが自動で解決したパッケージ（推移的依存）は、承認を待たずに導入してよい。
- 推移的依存を、直接参照として追加することは禁止する。

**ライセンスの確認と記録**
- `dotnet list package --include-transitive` で全パッケージのバージョンを確定し、ライセンスを確認して記録する。
- ライセンスの確認方法は次のいずれでもよい。
  - nuspecのlicense要素
  - nuspecのlicenseUrlが指す文書
  - パッケージに同梱されたライセンスファイル
- ライセンスが不明な場合や、想定外のライセンスだった場合でも、作業は止めない。台帳に「要確認」と記録して作業を続け、完了報告で報告する。

**停止する場合**
- §2.1にも推移的依存にも当たらないパッケージが、新たに必要になった場合。

## 3. 用語

| 用語 | 定義 |
|---|---|
| 項目 | 表の1行。種別は「大項目」「小項目」「マイルストーン」の3つ |
| 大項目 | 顧客に見せるレベルの工程。PPTに出力する対象 |
| 小項目 | 担当者に割り当てる細かいタスク。直前にある大項目に所属する |
| マイルストーン | 期間を持たない時点（納期、顧客レビューなど）。◆で表示する |
| 稼働日 | 土日、祝日、休日のいずれにも当たらない日 |
| CW | カレンダーウィーク。ISO 8601に従い、月曜始まりとし、1月4日を含む週をCW1とする |

## 4. データモデル

### 4.1 プロジェクト（ファイル1つ）

- プロジェクト名
- 項目の一覧（表示順を保持する）
- 設定：ステータスの一覧、担当者の一覧、カレンダー（祝日・休日）
- 表示設定：表示期間、日付の表示モード
- PPT出力設定：直前に出力したときの設定

JSONのルート要素には `schemaVersion: 1` を持たせる。

- **v0.4c：** 表示設定に「表示モード」（全表示 / チェック済みだけ表示）を追加する。ファイルに保存し、初期値は「全表示」とする。

### 4.2 項目

| フィールド | 内容 |
|---|---|
| Id | 内部の固定ID。行を並べ替えても変わらない |
| 種別 | 大項目 / 小項目 / マイルストーン |
| No | 表示用の番号（§5.1） |
| 項目 | 項目名（必須） |
| 前工程 | 0件以上の項目Id。画面ではNoで入力・表示する |
| ステータス | 設定済みのステータスから選ぶ。空欄も可 |
| 備考 | 自由記述 |
| 工数 | 1以上の整数（稼働日数）。マイルストーンは持たない |
| 手入力の開始日 | 任意。マイルストーンでは「日付」として扱う |
| 担当 | 設定済みの担当者から選ぶ。空欄も可 |
| PPTに表示 | 大項目とマイルストーンのみ。初期値はON |

計算で求まる値（開始日と完了予定日）は保存しない。読み込むたびに再計算する。

- **v0.4c：** フィールド「表示」（bool）を追加する。初期値はON。保存ファイルにこのフィールドが無い場合は、ONとして読み込む（既存ファイルとの互換）。

### 4.3 設定

- **ステータス**：名前と「完了扱い」フラグを持つ。初期値は「未着手」「着手」「済（完了扱い）」とする。
- **担当者**：名前と色を持つ。
- **カレンダー**：日付、名称、区分（祝 / 休）を持つ。土日は常に非稼働日とする。
- 他の `.srb.json` から、設定だけを取り込める。取り込み方は「置換」と「追加（重複は除く）」から選ぶ。

## 5. 表（左側）

### 5.1 列

列の並びは次のとおり：No / 種別 / 項目 / 前工程 / ステータス / 備考 / 工数 / 開始日 / 完了予定日 / 担当

**No**
- 小項目とマイルストーンに、表の上から順に番号を自動で振る。大項目には振らない。

**前工程**
- Noをカンマ区切りで入力する。存在しないNoを入力した場合は、エラーを表示する。

**開始日・完了予定日の表示**
- 計算で求まった値は、読み取り専用の見た目で表示する。

- **v0.4c：** 表の一番左（Noの左）に、チェックボックスの列「表示」を追加する。

### 5.2 操作

- 行の追加、挿入、削除、上下への移動。
- 行を削除する前に、確認を表示する。他の項目の前工程として参照されている場合は、参照元のNoも表示する。
- 未保存の変更がある場合は、保存するか確認する。上書き保存の前に `.bak` を1世代だけ残す。
- 元に戻す（Undo）機能は実装しない。

**入力の即時反映（v0.4）**
- コンボボックスの列（種別・ステータス・担当）は、値を選んだ時点で確定させる。
- 確定したら、再計算と再描画を行う。他のセルを選び直さなくても、帯の色などがすぐに変わること。
- テキストの列は、従来どおりセルの編集を確定した時点で反映する。

**チェックの連動（v0.4c）**
- チェックボックスの操作は、操作した時点で即時に反映する。
- 大項目のチェックを外したとき：配下の小項目とマイルストーンのチェックを、すべて外す。
- 大項目にチェックを入れたとき：配下の小項目とマイルストーンに、すべてチェックを入れる。
- 小項目またはマイルストーンにチェックを入れたとき：所属する大項目のチェックが外れていれば、その大項目にだけチェックを入れる。同じ大項目の配下にある、他の項目は変えない。
- 小項目またはマイルストーンのチェックを外したとき：他の行は変えない。配下のチェックがすべて外れても、大項目のチェックは外さない。
- 大項目に所属しないマイルストーンは、自分のチェックだけが変わる。

## 6. 日程計算

### 6.1 小項目

**開始日**
- 前工程が無い場合は、手入力の開始日を使う。空欄の場合は「未設定」とする。
- 前工程がある場合は、前工程のうち最も遅い完了日の翌稼働日とする。
  - 手入力の開始日の方が後であれば、手入力の開始日を採用する。
  - 手入力の開始日の方が前であれば、計算した開始日を採用し、警告を表示する。
- 開始日が非稼働日に当たる場合は、次の稼働日を開始日とし、警告を表示する。

**完了予定日**
- 開始日を1日目として稼働日を数え、工数日目に当たる稼働日を完了予定日とする。

### 6.2 マイルストーン

- 前工程がある場合は、前工程のうち最も遅い完了日の翌稼働日とする。
- 前工程が無い場合は、手入力の日付を使う。非稼働日でもよい。

### 6.3 大項目

- 配下に項目がある場合は、配下の項目の範囲を集計する。
  - 開始日：配下の項目のうち、最も早い開始日
  - 完了予定日：配下の項目のうち、最も遅い完了日
- 配下が無い場合は、小項目と同じ規則で計算する。

### 6.4 エラー処理

- 前工程が循環している場合は、関係する全ての行をエラーにする。アプリは落とさない。
- 工数が不正な場合は、その行を「未設定」とする。前工程に「未設定」の項目がある場合も、「未設定」とする。

### 6.5 再計算

- 入力が変わるたびに、全ての項目を即座に再計算する。想定規模は200行程度まで。

## 7. カレンダー表示（右側）

### 7.1 ヘッダ

上から次の4段で表示する。

1. 月
2. CW
3. 日
4. 曜（祝日・休日の場合は「祝」「休」と表示する）

### 7.2 本体

- 土日・祝・休の列は、灰色の背景にする。
- **今日の表示（v0.4）**
  - 全行を縦に貫く、1本の赤い縦線（幅2px程度）で示す。
  - 行ごとに枠や四角を描かない。
  - 行の境目で、線が途切れて見えないこと。
- **帯**
  - 小項目は、担当者の色で塗る。
  - 大項目は、担当者の色で塗り、小項目と区別できる表示にする。
  - マイルストーンは、◆で表示する。
  - 完了扱いの行は、濃い灰色にする。
- 非稼働日の列でも、帯は途切れさせない。

### 7.3 表示期間と日付の表示モード

**表示期間**
- 開始日と終了日を指定する。
- 「自動」ボタンで、全ての項目を含む期間を月単位で設定する。

**日付の表示モード**
- 「全日付」と「月曜のみ」から選ぶ。
- 表示期間を変更したときは、期間に合わせて初期値を自動で選ぶ。
  - 期間が92日以下：「全日付」
  - 期間が92日を超える：「月曜のみ」

### 7.4 操作性

- 左の表と右のカレンダーは、縦スクロールを同期させる。
- 横方向にスクロールしても、左の表は固定表示のままにする。

### 7.5 マウス・キー操作とズーム（v0.4）

| 操作 | 動作 |
|---|---|
| ホイール | 縦スクロール |
| Shift＋ホイール | 横スクロール（カレンダー方向） |
| Ctrl＋ホイール | ズーム（拡大・縮小） |
| Ctrl＋0 | ズームを100%に戻す |
| Ctrl＋「+」／Ctrl＋「-」 | ズーム（テンキーの＋／−も可） |

**ズームの仕様**
- 倍率は50%〜200%の範囲とし、1段階で10%ずつ変える。
- 対象は表とカレンダーの全体とする。文字サイズ、行の高さ、列の幅、ヘッダの高さを一緒に変える。
- 現在の倍率は、ステータスバーに表示する（例：`120%`）。
- 倍率はファイルに保存しない。起動時は100%とする。
- ズームしても、表示中の先頭行が大きく飛ばないようにする。

**応答性**
- 画面を共有しながらビデオ会議で操作するため、すばやく反応することが必要である。
- Ctrl＋ホイールを連続して操作しても、遅延なく追従すること。
- 確認条件：200行・6か月の表示で確認する。

### 7.6 表示モード（v0.4c）

- ツールバーで「全表示」と「チェック済みだけ表示」を切り替える。
- 全表示：チェックの状態にかかわらず、全ての行を表示する。
- チェック済みだけ表示：チェックが入っている行だけを、表とカレンダーに表示する。
  - このモードでチェックを外した行は、すぐに表示から消える。
  - 消えた行を表示に戻すには、全表示に切り替えてからチェックを入れる。
- 表示モードが変えるのは、見せ方だけとする。日程計算、前工程、No、大項目の期間の集計には影響しない。非表示の行も、計算の対象に含める。
- チェック済みだけ表示のときは、ステータスバーに「表示：チェック済みのみ（n / 全m行）」と表示する。

## 8. 設定画面

- **ステータス**：追加、削除、名前の変更、並べ替え、完了扱いの指定。
- **担当者**：追加、削除、名前の変更、並べ替え、色の指定（ColorDialog）。
  - **v0.4：** 一覧では、`#4472C4` などの色のコードの横に、その色で塗った見本を表示する。
- **カレンダー**：追加、削除、編集。
- **祝日の一括取り込み**
  - 受け付ける形式は `yyyy-MM-dd,名称` と `yyyy/M/d,名称` の2つ。
  - 文字コードはUTF-8とShift_JISに対応する。
- 使用中の項目を削除する場合は、確認を表示する。削除後、該当する値は空欄にする。

## 9. PNG出力（共有用）

- 現在の表示期間と表示モードで、表とカレンダーの全行を1枚のPNGとして出力する。
- 出力範囲は「全項目」と「大項目とマイルストーンのみ」から選べる。
- 初期のファイル名は `<プロジェクト名>_日程_yyyyMMdd.png` とする。

**出力への反映（v0.4c）**
- 出力する時点の表示モードに従い、全表示では全ての行、チェック済みだけ表示ではチェックが入っている行だけを出力の対象にする。
- 出力範囲の選択（「全項目」／「大項目とマイルストーンのみ」）は、表示モードで絞り込んだ後の行に対して適用する。

## 9.5 Excel出力（v0.4）

担当者が、自分の名前でフィルタをかけて使うことを想定した出力である。出力のみとし、取り込みは行わない。

**シートの構成**
- シートは1枚で、シート名は「日程」とする。
- 上部に、カレンダーのヘッダを4段（月・CW・日・曜）で置く。表示モードは画面の設定に従う。
- **v0.4c：月の段とCWの段は、画面と同じように、月ごと・週ごとにセルを結合する。**
  - 文字は、結合したセルの中で左揃えにする。
  - 表示範囲の両端で、月や週が範囲の途中から始まる場合や、範囲の途中で終わる場合は、範囲内の日数だけ結合する。

**見出し行と左側の列**
- ヘッダの直下の1行を、表の見出し行とする。見出し行には、オートフィルタを設定する。
- 左側の列は、次の順に並べる：No／種別／大項目／項目／前工程／ステータス／備考／工数／開始日／完了予定日／担当
- 「大項目」の列には、その行が所属する大項目の名前を入れる。大項目の行には、自分自身の名前を入れる。担当者で絞り込んでも、どの工程の作業か分かるようにするため。
- 開始日と完了予定日は、Excelの日付型にする（表示形式は `yyyy/mm/dd`）。
- 工数は、数値にする。
- 大項目の行は、太字にする。

**右側のカレンダー**
- 1日を1列とし、列の幅は狭くする。
- 帯は、セルの塗りつぶしを担当者の色にする。完了扱いの行は、濃い灰色にする。
- マイルストーンは、「◆」の文字を入れる。
- 土日・祝・休の列は、帯の無いセルを薄い灰色にする。

**ウィンドウ枠の固定**
- 見出し行の下、かつ「担当」の列の右で固定する。

**対象外**
- 数式、条件付き書式、取り込み、マクロ。

**出力の操作**
- 出力範囲は「全項目」と「大項目とマイルストーンのみ」から選べる。期間は、現在の表示期間とする。
- 保存先は、ファイル保存ダイアログで指定する。初期のファイル名は `<プロジェクト名>_日程_yyyyMMdd.xlsx` とする。
- 出力したxlsxは、OpenXmlValidatorでエラーが0件であること。

**出力への反映（v0.4c）**
- 出力する時点の表示モードに従い、全表示では全ての行、チェック済みだけ表示ではチェックが入っている行だけを出力の対象にする。
- 出力範囲の選択（「全項目」／「大項目とマイルストーンのみ」）は、表示モードで絞り込んだ後の行に対して適用する。

## 10. PPT出力

### 10.1 スライド

- スライドは1枚、16:9とする。フォントはMeiryo UIとする。
- 図形はすべてネイティブ図形とし、PowerPointで編集できるようにする。

### 10.2 レイアウト（上から順に）

**1. タイトル**
- プロジェクト名と出力日を表示する。

**2〜5. カレンダーの表（v0.4b：ヘッダと本体をPowerPointの表1つで作る）**

月・CW・日のヘッダ、大項目名の列、網掛け、グリッド線は、すべて1つの表（graphicFrame）で表す。罫線や網掛けを、図形として1本ずつ置くことはしない。

**表の構成**
- 列：左端に大項目名の列を1列置く。その右に、表示期間の1日を1列として並べる。
- 行：上から、月・CW・日の3行（ヘッダ）を置き、その下に大項目を1件1行で並べる。
  - 大項目に所属しないマイルストーンがある場合は、ヘッダの直下に専用の行を1行追加する。
- 左上の3×1セル（ヘッダ行の大項目名の列）は、結合して空欄にする。
- セルの内側の余白は0とする。

**ヘッダ**
- 月の段とCWの段は、セルを結合して作る（月ごと・週ごとに1セル）。文字は中央揃えにする。
- 範囲内の日数が5日未満の月・週は、セルを空欄にする。期間の両端などで、隣と文字が重ならないようにするため。
- 日の段
  - **v0.4c：日付の数字は、どのモードでも折り返さない。**
    - 「1」と「6」が2行に分かれるような表示はしない。
    - 日の段のセルは、テキストの折り返しをしない設定（`a:bodyPr wrap="none"`）にする。
    - あわせて、2桁の数字が1行でセルの幅に収まる文字サイズにする。
  - **全日付モード**
    - 各セルに日付の数字を入れる。
    - 文字サイズは、「30」をMeiryo UIで描いたときの幅（System.Drawingで実測）がセルの幅以下になる、最大のサイズとする。
      - 0.5pt刻みで決める。上限は10pt、下限は4ptとする。
    - 4ptでも収まらない場合は、4ptで出力し、月曜のみモードに切り替えることを促す警告を表示する。
  - **月曜のみモード（v0.4c：セルの結合は必須）**
    - 日の段は、月曜のセルとそれに続く6日分のセルを結合して、1つのセルにする。
      - 表示範囲の両端で7日に満たない週は、範囲内の日数だけ結合する。
    - 結合したセルに、月曜の日付を左揃えで入れる。文字サイズは、CWの段と同じにする。
    - 範囲内の日数が5日未満の週は、セルを空欄にする（CWの段と同じ規則）。

**本体**
- 大項目名の列に、大項目名を左揃えで入れる。
- 土日・祝・休の列のセルは、薄い灰色で塗る（ヘッダの日の段と本体の行。月とCWの段は塗らない）。
- 罫線（グリッド線）は、すべて細い薄灰色にする。
  - 横線：行の境目ごとに引く。
  - 縦線（全日付モード）：日ごとに引く。週の境目（月曜の左端）の線は、少し濃くする。
  - 縦線（月曜のみモード）：週の境目（月曜の左端）だけに引く。週の中の縦線は引かない。
- 行の高さは、本体の領域に収まるように均等に割り付ける。行が多いときの扱いは、§10.4に従う。

**表の上に置く図形（表には含めない）**
- 大項目の期間を表す矢印：該当する行の上に、その行の中央の高さで置く。色は担当者の色にする。完了扱いの大項目は灰色にする。
- マイルストーン
  - ◆と名称を、所属する大項目の行に置く。所属する大項目が無いものは、専用の行に置く。
  - ◆は矢印より前面に置き、白い縁取りを付ける。
  - **v0.4c：◆の大きさは固定とし、行の高さに比例させない。**
    - 大きさは、初版と同じにする。
    - 初版の値がコードや `docs/progress.md` から分からない場合は、一辺0.12インチ（約9pt）とする。
    - 行の高さが◆より小さい場合に限り、◆を行の高さの80%まで小さくする。
  - 名称は、◆の右側に隣接して置く（◆と同じ高さ）。右側の余白が足りない場合は、◆の真上に隣接して置く。◆から離れた位置には置かない。
- 今日の線：赤の破線の縦線を1本置く。表示するかどうかは選べる。
- これらの図形の位置は、表の列の位置から計算し、1日単位でぴったり揃える。

**重なりの順序（背面から）**
- 表 → 矢印 → ◆と名称 → 今日の線

**列数についての注意**
- PowerPointの「表の挿入」ダイアログで作れる表は、最大75列である。本ツールのように生成した表は、3か月の期間で約93列になり、この上限を超える。
- そのため、75列を超える表をPowerPointで開いたときに修復を求められないこと、編集できることを、人が確認する（§13.2）。
- 確認で問題が見つかった場合は、仕様を見直す。見直しの候補は、月曜のみモードを週単位の列にして列数を減らすこと。

### 10.3 出力ダイアログ

| 設定 | 内容 |
|---|---|
| 期間 | 初期値は、現在の表示期間 |
| 日付の表示モード | 全日付 / 月曜のみ |
| 今日の線 | ON / OFF |
| 保存先 | 初期のファイル名は `<プロジェクト名>_全体日程_yyyyMMdd.pptx` |

### 10.4 収まらない場合の扱い

**期間からはみ出す部分**
- 期間外の部分は描かない。
- 期間をまたぐ矢印は、期間の端で切って描く。

**行数が多い場合**
- 12行を超える場合は、警告を表示する。
- 行の高さを自動で縮めて、スライドに収める。

**日付の文字が入りきらない場合**
- 日付の文字の扱いは、§10.2の「日の段」に従う。

**出力への反映（v0.4c）**
- 出力する時点の表示モードに従い、全表示では全ての行、チェック済みだけ表示ではチェックが入っている行だけを出力の対象にする。
- 出力範囲の選択は、表示モードで絞り込んだ後の行に対して適用する。
- 既存の「PPTに表示」フラグを引き続き使い、表示モードで出力の対象になっており、かつ「PPTに表示」がONの大項目とマイルストーンだけを出力する。

- PPT：日の段のセルが、すべて `wrap="none"` であること。
