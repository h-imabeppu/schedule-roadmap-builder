**B. §10.2「ヘッダ」の「日の段」を、次の内容で置き換える**

- **v0.4c：日付の数字は、どのモードでも折り返さない。**
  - 「1」と「6」が2行に分かれるような表示はしない。
  - 日の段のセルは、テキストの折り返しをしない設定（`a:bodyPr wrap="none"`）にする。
  - あわせて、2桁の数字が1行でセルの幅に収まる文字サイズにする。
- **全日付モード**
  - 各セルに日付の数字を入れる。
  - 文字サイズは、「30」をMeiryo UIで描いたときの幅（System.Drawingで実測）がセルの幅以下になる、最大のサイズとする。
    - 0.5pt刻みで決める。上限は10pt、**下限は4pt**とする。
  - 4ptでも収まらない場合は、4ptで出力し、月曜のみモードに切り替えることを促す警告を表示する。
- **月曜のみモード（v0.4c：セルの結合は必須）**
  - 日の段は、月曜のセルとそれに続く6日分のセルを結合して、1つのセルにする。
    - 表示範囲の両端で7日に満たない週は、範囲内の日数だけ結合する。
  - 結合したセルに、月曜の日付を左揃えで入れる。文字サイズは、CWの段と同じにする。
  - 範囲内の日数が5日未満の週は、セルを空欄にする（CWの段と同じ規則）。

**C. §10.2「マイルストーン」の◆の大きさの記述を、次の内容で置き換える**

- ◆は矢印より前面に置き、白い縁取りを付ける。
- **v0.4c：◆の大きさは固定とし、行の高さに比例させない。**
  - 大きさは、初版と同じにする。
  - 初版の値がコードや `docs/progress.md` から分からない場合は、一辺0.12インチ（約9pt）とする。
  - 行の高さが◆より小さい場合に限り、◆を行の高さの80%まで小さくする。

**D. §9.5「シートの構成」に、次の内容を追加する**

- **v0.4c：月の段とCWの段は、画面と同じように、月ごと・週ごとにセルを結合する。**
  - 文字は、結合したセルの中で左揃えにする。
  - 表示範囲の両端で、月や週が範囲の途中から始まる場合や、範囲の途中で終わる場合は、範囲内の日数だけ結合する。

**E. §13.1に「v0.4cで追加するテスト」を追加する**

- PPT：日の段のセルが、すべて `wrap="none"` であること。
- PPT：全日付モードで、日の段の文字サイズが4pt以上10pt以下であること。
  - 「30」を実測した幅が、セルの幅以下であること。4ptの下限に当たった場合は除く。
- PPT：月曜のみモードで、日の段が週ごとに結合されていること（gridSpan）。
- PPT：◆の大きさが、行の高さによらず一定であること（行数1と行数10で同じ大きさ）。
- Excel：月とCWの段に、月ごと・週ごとの結合セル（mergeCell）があること。
  - 結合の範囲が、カレンダーの列と一致すること。

**F. §13.2に、次の内容を追加する**

- v0.4c：次の3点を確認する。
  - PPTの日付が、折り返されずに1行で読めること（4か月・全日付と、4か月・月曜のみ）。
  - ◆の大きさが、初版と同じくらいであること。
  - Excelの月とCWが、セル結合されていること。

**G. 表示チェックと表示モードを追加する（v0.4c）**

次の内容を、§4・§5・§7・§9・§9.5・§10・§11・§13に追記する。追記する位置は、それぞれの節の末尾でよい。

- **§4.2 項目**
  - フィールド「表示」（bool）を追加する。初期値はON。
  - 保存ファイルにこのフィールドが無い場合は、ONとして読み込む（既存ファイルとの互換）。
- **§4.1 プロジェクト**
  - 表示設定に、「表示モード」（全表示 / チェック済みだけ表示）を追加する。
  - 表示モードはファイルに保存する。初期値は「全表示」とする。
- **§5.1 列**
  - 表の一番左（Noの左）に、チェックボックスの列「表示」を追加する。
- **§5.2 チェックの連動**
  - チェックボックスの操作は、操作した時点で即時に反映する。
  - 大項目のチェックを外したとき：配下の小項目とマイルストーンのチェックを、すべて外す。
  - 大項目にチェックを入れたとき：配下の小項目とマイルストーンに、すべてチェックを入れる。
  - 小項目またはマイルストーンにチェックを入れたとき：
    - 所属する大項目のチェックが外れていれば、その大項目にだけチェックを入れる。
    - 同じ大項目の配下にある、他の項目は変えない。
  - 小項目またはマイルストーンのチェックを外したとき：
    - 他の行は変えない。
    - 配下のチェックがすべて外れても、大項目のチェックは外さない。
  - 大項目に所属しないマイルストーンは、自分のチェックだけが変わる。
- **§7 表示モード**
  - ツールバーで、「全表示」と「チェック済みだけ表示」を切り替える。
  - 全表示：チェックの状態にかかわらず、全ての行を表示する。
  - チェック済みだけ表示：チェックが入っている行だけを、表とカレンダーに表示する。
    - このモードでチェックを外した行は、すぐに表示から消える。
    - 消えた行を表示に戻すには、全表示に切り替えてからチェックを入れる。
  - 表示モードが変えるのは、見せ方だけとする。
    - 日程計算、前工程、No、大項目の期間の集計には影響しない。
    - 非表示の行も、計算の対象に含める。
  - チェック済みだけ表示のときは、ステータスバーに「表示：チェック済みのみ（n / 全m行）」と表示する。
- **出力への反映（§9・§9.5・§10）**
  - PNG出力、Excel出力、PPT出力は、出力する時点の表示モードに従う。
    - 全表示のときは、全ての行を出力の対象にする。
    - チェック済みだけ表示のときは、チェックが入っている行だけを出力の対象にする。
  - 出力範囲の選択（「全項目」／「大項目とマイルストーンのみ」）は、表示モードで絞り込んだ後の行に対して適用する。
  - PPTでは、既存の「PPTに表示」フラグを引き続き使う。次の両方を満たす大項目とマイルストーンだけを出力する。
    - 表示モードで出力の対象になっている。
    - 「PPTに表示」がON。
- **§13.1 テスト**
  - チェックの連動：上記の4つの規則と、所属の無いマイルストーンの扱い。
  - 表示モードによる行の絞り込み。
  - 非表示の行があっても、日程計算の結果が変わらないこと。
  - 「表示」フィールドの無い古いJSONを、全行ONとして読み込めること。
  - チェック済みだけ表示のとき、Excel・PPT・PNGに出力される行数が、絞り込み後の行数と一致すること。
  - PPTでは、「PPTに表示」がOFFの行を出力しないこと。
- **§13.2 人の確認**
  - チェックの連動
  - 表示モードの切り替え
  - 出力への反映
